KEERTHI PROFESSIONAL PORTFOLIO

IMPORTANT:
This version has all CSS embedded directly inside index.html.
You only need to open index.html. No separate CSS file is required.

For GitHub Pages:
1. Create a repository named portfolio.
2. Upload index.html.
3. Go to Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select main and /root.
6. Save.
